# Sysadmin Academy - Frontend

Frontend React + Vite untuk aplikasi pembelajaran sysadmin.

## Setup

```bash
npm install
npm run dev
```

Server: http://localhost:5173

## Build

```bash
npm run build
```

## Structure

- `src/pages/` - Halaman utama
- `src/components/` - Komponen reusable
- `src/api/` - API client
- `src/stores/` - State management (Zustand)
- `src/hooks/` - Custom hooks
